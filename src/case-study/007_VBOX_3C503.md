# VirtualBox 3C503: Tail-Clipping Underflow Expands a Small DMA into a Huge One

## Summary

This bug comes from a broken tail-clipping formula in the 3C503 DMA path. When the DMA address is placed near the end of the local RAM window, the clipping code computes a skip length with the wrong arithmetic direction. That skip value can become much larger than the original transfer size, and subtracting it from a 16-bit transfer length underflows into a very large value. The inflated length is then passed into the DMA helper together with an unchecked offset.

## Trigger Chain

1. The guest places the DMA address near the end of the 16 KB local RAM area.
2. The guest requests a small DMA transfer.
3. The emulator detects that the transfer crosses the buffer tail.
4. The tail-clipping formula computes an oversized `cbToSkip`.
5. `cbToXfer -= cbToSkip` underflows in a 16-bit variable.
6. The DMA helper is called with a huge length and an unchecked offset into `abLocalRAM`.

## Vulnerable Logic

```c
if ((uDmaAddr - base + cbToXfer) > sizeof(abLocalRAM)) {
    cbToSkip = sizeof(abLocalRAM) - (base - uDmaAddr + cbToXfer);
    cbToXfer -= cbToSkip;
}

rc = PDMDevHlpDMAWriteMemory(pDevIns, nchan,
                             &pThis->abLocalRAM[uDmaAddr - base],
                             dma_pos, cbToXfer, &cbXferred);
```

## Fixed Logic

```c
uint32_t offset = (uint32_t)((int32_t)uDmaAddr - base);

if (offset >= sizeof(pThis->abLocalRAM)) {
    cbToXfer = 0;
} else {
    uint32_t max_len = sizeof(pThis->abLocalRAM) - offset;
    if (cbToXfer > max_len)
        cbToXfer = (uint16_t)max_len;
}
```

## Analysis

This is not just an out-of-bounds bug. It is an arithmetic bug first and a memory corruption bug second. A transfer that should have been truncated at the buffer tail is instead expanded by unsigned underflow, which is much worse than a simple missing bounds check. The correct repair is to stop doing tail clipping with mixed-sign or backward arithmetic and instead compute `offset` and `remaining capacity` in a wider type before issuing the DMA.
